05 — Hash function

A formula turns a key into an index.

h(key) = key mod table_size

The output is always a valid location in the table.

06 — Example

Where does key 10 go?

h(10) = 10 mod 7 = 3

08 — Collision

Two keys. One index.

10 mod 7 = 3
17 mod 7 = 3

A collision occurs when different keys produce the same index.

11 — Load factor

How full is the table?

Load factor = number of items / table size

Higher load factor → more collisions → slower performance.

14 — Recap

The big idea: speed.

  • Hashing maps keys to indexes.
  • Hash functions calculate positions.
  • Collisions share an index.
  • Chaining and open addressing resolve collisions.
  • Hash tables are usually O(1).
